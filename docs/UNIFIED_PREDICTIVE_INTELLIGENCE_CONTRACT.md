Status: SPECIFICATION ONLY. This document does not certify execution, deployment of model engines, or accuracy. Preserve all existing warehouse data, rules, receipts, and NO_TICKET gates.

## Trigger
RUN FRAMEWORK on an uploaded prop: extract sport, player, game, market, exact line, platform, and snapshot timestamp. If any required identifier is missing, request it; never invent a prop. Freeze inputs before prediction.

## Data and evidence
Retain Player DNA, Opponent DNA, workload, availability/projected roles, L52 historical reconstruction, 25,000 actual sequential simulations per prop, independent line-blind AI, adversarial opposite-side tests, and all existing release controls. Data sources require provenance, timestamps, fallbacks, and verification; do not claim an unavailable feed succeeded.

## Ten differentiated prediction methods
Each must produce OVER or UNDER, projected statistic and/or calibrated probability, rationale, provenance, uncertainty and method identifier: Forecast (probability), Project (minutes/opportunity/conversion), Estimate (statistical expectation), Anticipate (game scenarios), Model (matchup/role model), Prognosticate (structured judgment), Extrapolate (trend with regression), Infer (latent factors), Simulate (actual trial distribution), Assess (risk/stress). Do not duplicate a single model under ten names. Missing inputs must be flagged, not fabricated. Distinguish method agreement from true hit probability.

## Historical coverage chart
For each exact uploaded line report OVER, UNDER, PUSH and denominator for L5/L10/L15/L20/L25/L52, current season, last season, and career, plus game-by-game values and dates, available game counts, and chart. Rolling windows overlap. Integer equality is PUSH. Rookies use all available verified recent NBA games; college/G League/other competition stays separately labeled. No fabricated L52 or unavailable career counts. Add home/away, role splits, and sensitivity at -1.0, -0.5, +0.5, +1.0, including flip points.

Final report: exact prop; historical coverage chart; ten method decisions; Player/Opponent DNA; availability; simulation provenance; Blind AI comparison; adversarial disagreements; sensitivity; OVER/UNDER conclusion; uncertainty; alternative lines; immutable receipt.
